# Disabilities Mod (`v1.0.1`)

기본 **10분마다 무작위 질병 또는 공포증(총 44종)**이 하나씩 발현되는 Minecraft Fabric 서바이벌 챌린지 모드입니다.

* **지원 환경**: Minecraft `26.3` / Fabric Loader `>=0.20.1` / Fabric API / Java `25`
* **설치 위치**: 클라이언트 + 서버 양측 필수 (`environment: "*"`)
* **라이선스**: MIT

---

## 주요 기능

* **자동 발현 타이머**: 기본 10분마다 온라인 플레이어에게 아직 보유하지 않은 랜덤 질병 1종 부여 (월드 데이터 `disabilities_state.txt`에 자동 저장)
* **질병 도감 GUI (`/질병도감`)**:
  * 44종 전체 질병/공포증 목록과 설명 확인, **한글/영어/설명 실시간 검색**, `전체 / 보유 중` 필터, 언어 전환 지원
  * **OP 권한** 보유 시 상단에서 접속 중인 플레이어를 선택해 질병을 클릭 한 번으로 즉시 **발현/제거** 가능
* **치료제 아이템 (`disabilities:cure`)**:
  * 우클릭 시 현재 내가 보유 중인 질병 목록이 GUI로 열리며, 원하는 질병 1개를 선택해 치료 가능
  * **조합법**: 발광석 가루 4개 + 황금 사과 1개 + 유리병 1개 (크리에이티브 `음식 및 음료` 탭에서도 획득 가능)
* **설정 파일 (`config/disabilities.properties`)**:
  * `language=auto` (마인크래프트 게임 언어 자동 추적, `ko` / `en` / `auto` 지원)
  * `acrophobia_y=65` (고소공포증 발동 Y좌표, 멀티플레이어에서는 **서버 설정**이 클라이언트에 자동 동기화됨)
  * `tourette_messages=` (투렛 증후군 커스텀 채팅 메시지, 쉼표 `,`로 구분해 자유롭게 추가/삭제 가능. 비워두면 마인크래프트 랜덤 단어 사용)
  * 파일 수정 시 재시작 없이 실시간 핫 리로드 및 서버→클라이언트 자동 동기화 지원
* **HUD 토글 키**: 기본 **`K`** 키로 좌측 상단 질병 목록 HUD 표시/숨김 전환 (인벤토리 등 화면을 연 상태에서 마우스를 올리면 설명 툴팁 표시)

## 명령어

### 일반 플레이어 (권한 불필요)
| 명령어 | 설명 |
| :--- | :--- |
| `/질병도감` | 질병 도감 GUI 열기 (별칭: `/도감`, `/disbook`) |

### 관리자 전용 (OP 권한 필요, `/disability` 또는 `/dis`)
| 명령어 | 설명 |
| :--- | :--- |
| `/disability give <대상> <질병명\|all\|random>` | 대상 플레이어에게 특정 질병(또는 전체/랜덤) 부여 |
| `/disability remove <대상> <질병명\|all\|random>` | 대상 플레이어에게서 특정 질병(또는 전체/랜덤) 제거 |
| `/disability next [대상]` | 대상(미입력 시 전체 플레이어)에게 랜덤 질병 1종 즉시 부여 |
| `/disability timer <분(0.05~720)>` | 자동 발현 타이머 주기 변경 |
| `/disability timer off` | 자동 발현 타이머 비활성화 |
| `/disability list [대상]` | 보유 중인 질병 목록 출력 |
| `/disability reset` | 모든 플레이어의 질병 초기화 및 10분 타이머 복구 |
| `/disability lang <en\|ko\|auto>` | 표시 언어 변경 및 `config/disabilities.properties` 저장 |
| `/disability config acrophobia [Y좌표]` | 고소공포증 발동 높이 확인 또는 변경 (`-64~320`, 서버→클라 자동 동기화) |
| `/disability config tourette list` | 설정된 커스텀 투렛 메시지 목록 및 번호 확인 |
| `/disability config tourette add <메시지>` | 커스텀 투렛 메시지 추가 |
| `/disability config tourette remove <번호\|메시지>` | 번호 또는 문구로 커스텀 투렛 메시지 삭제 |
| `/disability config tourette clear` | 커스텀 투렛 메시지 전체 초기화 (기본 랜덤 단어로 복귀) |
| `/disability reload` | 설정 파일(`config/disabilities.properties`) 즉시 다시 불러오기 및 동기화 |

## 질병 및 공포증 목록 (총 44종)

### 👁️ 감각 / 시각 / 청각 (12종)
| 한국어명 | 영어명 (`ID`) | 효과 |
| :--- | :--- | :--- |
| **실명** | Blind (`blind`) | 지속적인 실명 효과가 적용되며 달리기를 할 수 없습니다. |
| **색맹** | Color Blind (`color_blind`) | 화면 전체가 흑백(그레이스케일)으로 렌더링됩니다. |
| **청각 장애** | Deaf (`deaf`) | 게임 내 모든 소리가 들리지 않습니다. |
| **복시** | Diplopia (`diplopia`) | 화면 전체가 어긋난 두 개의 상으로 겹쳐 보입니다. |
| **난시** | Astigmatism (`astigmatism`) | 청크 렌더 거리가 **1청크**로 강제 제한되어 멀리 있는 것이 보이지 않습니다. |
| **근시** | Myopia (`myopia`) | 가까이 있는 사물(약 4.5~6.2블록 이내)이 검게 가려져 실루엣만 보입니다. |
| **녹내장** | Glaucoma (`glaucoma`) | 주변 시야가 검게 좁아지는 터널 비전이 적용됩니다. (핫바/UI는 유지) |
| **안면실인증** | Prosopagnosia (`prosopagnosia`) | 모든 몹이 똑같은 스티브 모델로 보이며 이름표와 히트박스 구별이 차단됩니다. |
| **난독증** | Dyslexia (`dyslexia`) | 대부분의 게임 내 텍스트가 깨져 읽을 수 없습니다. |
| **척추측만증** | Scoliosis (`scoliosis`) | 카메라 시야가 영구적으로 기울어집니다. |
| **현기증** | Vertigo (`vertigo`) | 주기적으로 멀미와 함께 화면이 크게 기울고 회전합니다. |
| **질병인식불능증** | Anosognosia (`anosognosia`) | 타이머와 `질병인식불능증` 자체만 표시되고 나머지 보유 질병·알림이 숨겨지며, 치료제 GUI에서는 모든 항목이 `???`로, 도감에서는 모든 질병의 보유 표시가 `[?]`로 가려집니다. |

| 한국어명 | 영어명 (`ID`) | 효과 |

| **암** | Cancer (`cancer`) | 시간이 지날수록 최대 체력이 서서히 감소합니다(최소 3하트까지). |

| **파킨슨병** | Parkinson's (`parkinsons`) | 조준점과 실제 클릭 판정이 끊임없이 떨립니다. |

| **조현병** | Schizophrenia (`schizophrenia`) | 가짜 발소리·몹 소리가 들리며 주변에 그림자 인간 환각이 나타납니다. |
| **환각** | Hallucination (`hallucination`) | 존재하지 않는 가짜 몹(좀비, 크리퍼, 스켈레톤, 거미, 엔더맨)이 주변에 나타나 다가오며, 피해를 주지 않고 때리면 연기와 함께 사라집니다. |
| **강박장애** | OCD (`ocd`) | 핫바 위에 무작위 강박 과제(블록 설치, 채굴, 점프, 웅크리기)가 표시됩니다. 제한 시간 내 미달성하거나 **목표 횟수를 초과**하면 피해를 입습니다. |

### 😨 공포증 (7종)
| 한국어명 | 영어명 (`ID`) | 효과 |
| :--- | :--- | :--- |
| **폐소공포증** | Claustrophobia (`claustrophobia`) | 천장이 막힌 실내/동굴이거나 사방 중 3면 이상이 막힌 좁은 공간에 있으면 지속 피해를 입습니다. |
| **어둠공포증** | Nyctophobia (`nyctophobia`) | 밝기가 **4 이하**인 어두운 곳에서 어둠, 구속 II, 지속 피해를 입습니다. |
| **물공포증** | Aquaphobia (`aquaphobia`) | 물에 들어가거나 비를 맞으면 지속 피해를 입습니다. |
| **불공포증** | Pyrophobia (`pyrophobia`) | 반경 4블록 이내에 용암, 불, 횃불, 모닥불, 랜턴, 마그마 블록이 있으면 공황 디버프(구속 II, 나약함 II, 멀미)에 걸립니다. |
| **광장공포증** | Agoraphobia (`agoraphobia`) | 하늘이 뚫리고 사방이 탁 트인 야외에 5초 이상 머무르면 공황 디버프(구속 II, 나약함, 멀미)에 걸립니다. |
| **고소공포증** | Acrophobia (`acrophobia`) | **Y좌표 65 이상**에 있으면 화면 떨림과 함께 멀미, 구속 II가 적용됩니다. |
| **거미공포증** | Arachnophobia (`arachnophobia`) | 반경 10블록 이내에 거미나 동굴 거미가 있으면 가까워질수록 강한 화면 떨림과 함께 나약함 II, 구속 II가 적용됩니다. |
